KI Starter Studio

KI Starter Studio ist das interne Veröffentlichungswerkzeug von KI Starter. Es plant die eigenen Lernvideos von KI Starter („KI im Betrieb“, Tipps zu KI für Selbstständige und Handwerksbetriebe) und veröffentlicht sie auf dem eigenen TikTok-Konto von KI Starter.

So funktioniert es

  1. Der Betreiber verbindet einmalig das eigene TikTok-Konto über „Mit TikTok anmelden“ (Login Kit).
  2. Die fertigen Videos stehen mit Text in einer Warteschlange.
  3. Zur geplanten Zeit lädt das Werkzeug das Video über die Content Posting API auf das eigene Konto hoch.

Es werden keine Inhalte anderer Personen gelesen oder veröffentlicht. Das Werkzeug wird ausschließlich vom Betreiber für das eigene Konto genutzt.
